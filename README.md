# 雪庐记账 · 后端（intern-day-2-backend）

第二天练习项目：登录鉴权 + 个人记账接口，Python + FastAPI + SQLite。

## 项目主题

登录后记录个人收支，按月份查看明细与月度汇总。所有数据均为虚构内容。

## 功能范围

**必做**：健康检查、账号密码登录、获取当前用户、退出登录。

**自选功能**：个人记账——新增收入/支出、按月查询本人账目、删除本人账目、月度收支汇总。

**暂不做**：注册、找回密码、短信/第三方登录、角色权限。

## 验收条件

- 错误账号与错误密码返回同一句提示，不暴露账号是否存在。
- 未携带、伪造、已过期、已退出的令牌访问受保护接口一律返回 `401`。
- 账目只能由本人读写，删除他人记录不泄露记录是否存在。
- 在仓库根目录执行 `docker compose up --build` 即可独立启动，不依赖前端仓库目录。

## 接口约定

| 方法 | 路径 | 是否需登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/health` | 否 | 健康检查 |
| POST | `/auth/login` | 否 | 账号密码登录 |
| GET | `/auth/me` | 是 | 获取当前用户 |
| POST | `/auth/logout` | 是 | 退出登录 |
| POST | `/ledger/entries` | 是 | 新增账目 |
| GET | `/ledger/entries?month=YYYY-MM` | 是 | 按月查看本人账目 |
| DELETE | `/ledger/entries/{id}` | 是 | 删除本人账目 |
| GET | `/ledger/summary?month=YYYY-MM` | 是 | 月度收支汇总 |

金额对外用「元」，落库用「分」。
